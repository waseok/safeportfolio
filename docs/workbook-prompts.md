# SAFE 포트폴리오 워크북 이미지 생성 프롬프트 (전체 20페이지)

---

## 공통 스타일 지시사항 (모든 페이지 공통 적용)

```
모든 페이지 공통 스타일:
- 사이즈: A4 세로 (210mm × 297mm), 인쇄용 해상도
- 색상 테마: 주황색 계열 (#FF8C00, #FFA040, #FFD700, 흰색 배경)
- 디자인: 플랫 일러스트, 깔끔하고 현대적인 교육 자료 스타일
- 대상: 초등학교 3~6학년
- 폰트 스타일: 둥글고 귀여운 고딕 계열 한글 폰트
- 학생이 직접 쓸 수 있는 빈 칸, 줄, 표를 충분히 포함
- 사진 없이 일러스트(그림)만 사용
- 캐릭터: 안전 조끼를 입은 귀여운 초등학생 남녀 캐릭터

⭐ 특별 지시:
- 페이지 4, 5, 6에는 "SAFE 포트폴리오 웹사이트 스크린샷" 삽입 영역이 있습니다.
- 프롬프트의 "빈 직사각형 박스" 영역을 그대로 두면, 
  사용자가 실제 사이트의 캡처 사진을 잘라 붙일 수 있습니다.
- 박스 크기와 가이드 텍스트를 따라주세요.
```

## 소주제 1 — 세이프 포트폴리오 활용법 안내 표지

```
[이미지 생성 프롬프트]

A4 세로 소주제 섹션 표지 디자인. 워크북 내부 파트 표지 스타일.

=== 전체 레이아웃 ===
배경: 흰색 바탕 위 주황색(#FF8C00) + 연한 주황(#FFF3E0) 조합

=== 상단 영역 (전체 높이 30%) ===
꽉 찬 주황색 그라데이션 블록 (위에서 아래로: #FF8C00 → #FFA040).
왼쪽에 큰 흰색 텍스트 2줄:
  첫째 줄: "소주제 1" (작은 글씨, 흰색 반투명)
  둘째 줄: "세이프 포트폴리오" (크고 굵은 흰색)
  셋째 줄: "활용법 안내" (크고 굵은 흰색)
오른쪽에 노트북+방패 조합 아이콘 일러스트 (흰색 선화 스타일, 크게).

=== 중앙 영역 (전체 높이 45%) ===
중앙 좌측 (60% 너비):
  연주황(#FFF8EE) 둥근 사각형 박스 안에 학습 목표 텍스트:
    📌 "학습 목표"  (주황색 소제목)
    "① SAFE 포트폴리오 사이트에 접속할 수 있다."
    "② 학급코드와 이름으로 학생 입장을 할 수 있다."
    "③ 안전과제를 확인하고 인증 사진을 업로드할 수 있다."
    "④ 포인트를 확인하고 상점을 이용할 수 있다."
  (각 항목 앞에 주황색 체크박스 □ 아이콘)

중앙 우측 (40% 너비):
  스마트폰을 들고 환하게 웃는 초등학생 캐릭터 일러스트
  (안전 조끼 착용, 화면에 별 포인트 아이콘이 보임)
  캐릭터 위에 말풍선: "함께 배워봐요! 🌟"

=== 하단 영역 (전체 높이 25%) ===
주황 점선 구분선.

아이콘 5개 가로 나열 (각각 원형 주황 배경):
  💻 사이트 접속  →  🔑 학생 입장  →  📝 과제 확인  →  📷 사진 인증  →  ⭐ 포인트 획득
  각 아이콘 아래 작은 텍스트 설명.

맨 아래: 연주황 띠 배너.
  왼쪽: "SAFE 포트폴리오 워크북"
  오른쪽: 페이지 번호 영역 (비워둠)

=== 디자인 톤 ===
전체적으로 밝고 따뜻한 주황 계열, 초등학생 친화적,
플랫 일러스트 스타일, 인쇄용 A4 세로, 300dpi
```

```
[이미지 생성 프롬프트]
```

```
"SAFE 포트폴리오는 안전 실천을 기록하고 인증하는 프로그램이에요.

중앙: 2×2 그리드 카드 레이아웃 (각 카드 둥근 모서리, 주황색 테두리)
- 카드 1 (상단 좌): 선생님이 노트북 앞에 앉아 과제 등록하는 일러스트 + "① 선생님이 안전과제를 등록해요"

- 카드 3 (하단 좌): 스마트폰으로 사진 찍는 학생 일러스트 + "③ 사진으로 인증해요"
- 카드 4 (하단 우): 별 포인트 배지와 상점 아이템 일러스트 + "④ 포인트로 보상을 받아요"

카드 사이에 주황색 화살표로 연결.

하단: 빈 줄 3줄 + 안내문 "SAFE 포트폴리오를 사용해보고 싶은 이유를 적어보세요!"

페이지 번호: 하단 중앙 "3"
```
